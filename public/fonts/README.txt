Self-hosted font subsets.

  archivo-var-latin.woff2    Archivo, variable 400-900, Latin subset
  plexmono-400/500/600       IBM Plex Mono, Latin subset

Both families are licensed under the SIL Open Font License 1.1; the full text
of each licence sits beside the files. They are bundled rather than loaded from
a CDN because this app has to work with the radio off - a Google Fonts request
that fails is a page with no typography, in a basement, mid-session.

Subsets were taken from the Google Fonts CDN and cover U+0000-00FF plus the
punctuation the interface actually uses. Total: 64 KB.
